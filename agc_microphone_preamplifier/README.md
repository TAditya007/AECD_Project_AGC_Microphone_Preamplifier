# AECD project report template

1. Open `main.tex` and edit the project-information block near the top.
2. Keep `klh_logo.png`, `main.tex`, and `references.bib` in the same folder.
3. Replace the instructional text and framed figure placeholders with the batch's own material.
4. Add every external source to `references.bib` and cite it with `\cite{key}`.
5. Compile with `latexmk -pdf main.tex`, or run `pdflatex`, `bibtex`, and `pdflatex` twice.
6. Submit the compiled PDF together with the `.tex`, `.bib`, figure files, Multisim file, and any measured-data file requested by the instructor.

Use only an isolated low-voltage supply or a faculty-approved adapter. Never wire mains voltage on a breadboard.
