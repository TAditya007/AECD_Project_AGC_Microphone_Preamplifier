\section{Simulation Objectives}

Before hardware construction, the design of Chapter~\ref{ch:circuitdesign} should be verified in Multisim to confirm, at minimum:
\begin{itemize}
    \item Correct DC operating (bias) point for every active device, with no device driven outside its safe operating region;
    \item Nominal (unregulated) gain and frequency response of the U1A (VGA) stage;
    \item Correct AGC behaviour under transient conditions -- i.e., that the output level is compressed towards the target range as the input amplitude is swept or stepped across the specified range;
    \item Attack and release time behaviour consistent with the values targeted in the design.
\end{itemize}

\subsection{Planned Transient Test Conditions and Target Behaviour}

The transient tests are planned using a 1~kHz sine-wave input at 0~V DC offset, at three input amplitudes: 10~mV, 50~mV, and 100~mV. \textbf{The values below are the project's target/expected behaviour, derived from the design intent of Section~\ref{ch:circuitdesign}; they are not measured or simulated results}, since no simulation has yet been run on the final circuit (Section~\ref{sec:sim-results-empty}):

\begin{itemize}
    \item 10~mV input $\rightarrow$ target overall gain $\approx$50$\times$ $\rightarrow$ target output $\approx$0.5~V;
    \item 50~mV input $\rightarrow$ target overall gain $\approx$10$\times$ $\rightarrow$ target output $\approx$0.5~V;
    \item 100~mV input $\rightarrow$ target overall gain $\approx$5$\times$ $\rightarrow$ target output $\approx$0.5~V.
\end{itemize}

This target behaviour illustrates the intended AGC action: as the input amplitude increases, the overall gain is expected to decrease correspondingly, so that the output amplitude remains approximately constant near the 0.5~V target.
